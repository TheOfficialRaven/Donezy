# Donezy - Gamified Productivity Platform

Level up your productivity with Donezy's immersive quest system, smart notes, and achievement tracking. Dark-themed premium experience.

## Tech Stack

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Getting Started

Make sure you have Node.js & npm installed - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start the development server
npm run dev
```

## Deployment

Build the project for production:

```sh
npm run build
```

Then deploy the `dist` folder to your preferred hosting provider.
